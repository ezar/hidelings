# Decisions

Short architecture decision records, one file per decision, numbered in order: `0001-short-title.md`.

Each record has four parts:

- **Context**: what forced the decision.
- **Options**: what was considered.
- **Decision**: what was chosen.
- **Consequences**: what it changes and what it costs.

The first record, `0001-m0-results.md`, closes M0 with the iPhone measurements from the PoC protocol (see `poc/README.md`).
