# hidelings

Little creatures that hide behind the real things in your house. Point the phone around the room, spot one peeking out from behind the sofa, and catch it with a tap or a pinch.

## Contents

- [`poc/`](poc/): M0 spike. Checks whether iPhone Safari, without WebXR, can make the illusion convincing using monocular AI depth (Depth Anything V2 Small), gyroscope anchoring (3DoF) and MediaPipe hands. See [`poc/README.md`](poc/README.md) for how to run it and the test protocol.

Once GitHub Pages is enabled on this repo, the PoC is served at `https://ezar.github.io/hidelings/poc/`.
